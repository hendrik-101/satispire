# Satispire

Parametric production and multistory factory planning for Satisfactory.

Satispire is in the architecture and planning phase. It is an independent fan project and is not affiliated with Coffee Stain.

The goal is a deterministic production graph and parameter-driven multistory layout variants with a shared footprint, cooperative sessions, and a common API for UI and MCP clients.

This repository currently contains planning documentation only. It contains no game assets or product code.
