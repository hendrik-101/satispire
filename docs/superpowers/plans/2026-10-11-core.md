# Executable planning core implementation plan

**Goal:** Deliver a reproducible synthetic planning slice through a CLI and shared UI/MCP application boundary.

**Architecture:** Independent production and geometry modules, authorized room commands, thin protocol adapters. TanStack Start workspace implementation awaits the approved design. Convex transactions are tested without assuming a deployed backend.

**Spec:** `docs/architecture.md`, authorized task and issues #1–#12.

## Checks

- [ ] Domain tests fail before implementation, then pass with known answers and error cases.
- [ ] Exact DAG solver supports multiple targets/shared dependencies; malformed, cyclic, unsupported inputs fail.
- [ ] Synthetic geometry generates uneven rows, rotations, equal story footprint and multi-floor lift reservations.
- [ ] Room changes enforce roles, expected revisions and idempotency across eight members.
- [ ] MCP client executes tools; WebMCP capability detection and fallback run in a real browser.
- [ ] CLI solves and generates a complete sample; `npm ci`/lint/typecheck/coverage/build pass.
- [ ] Draft PR, CI and available code/security reviews are checked on final head. Unavailable review blocks Ready.

## Review focus

Cross-room identity injection, stale retries with changed payload, unreasonable solver/layout input sizes, unverified game geometry and unavailable browser protocol support must fail honestly. The owning module's tests cover each.
