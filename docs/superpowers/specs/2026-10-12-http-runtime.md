# Satispire HTTP runtime

The authorized follow-up supplies a small executable Node/Container test runtime on PR15 2bf6769. It does not merge PR13–15, deploy, provision Convex, modify another repository, change VPS/DNS/tunnel/credentials or create paid services. The writer executes inline; a read-only scout verifies squash integration separately.

Use pinned Node 24.19.0/npm 11.9.0 and promote the existing locked srvx 0.11.22 adapter to a direct production dependency. Import the built TanStack Fetch entry, serve only generated client files, and expose GET/HEAD /healthz and /version.json. This slice is client-local; HTTP writes are unsupported and return 405. Default host is loopback, PORT is explicit/validated, forwarded headers are not trusted. A fixed build-info file records the supplied full lowercase commit SHA; runtime environment cannot change its revision. Missing/invalid bundles or metadata fail before listening. Adapter errors return a generic 500. SIGTERM drains and closes within the documented bounded timeout.

A multi-stage Docker image builds the exact checked-out source and runtime metadata, then runs only production dependencies/output as the existing node user. Its builtin Node health probe avoids extra CLI packages. No repository credentials/source/ignored local files enter the build context. The test Compose template pins an operator-supplied image digest, publishes only operator-selected loopback port, joins an already-existing external Cloudflare network, has no persistent application volumes and drops privileges. It is a contract handed to the infrastructure owner, not an installed Ansible role. Rollback redeploys the prior exact digest/revision without data migrations.
