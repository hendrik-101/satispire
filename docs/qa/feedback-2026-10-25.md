# Site feedback corrections, 25 October 2026

The candidate follows the existing floor-centered design contract and is based on main `986fb1a`.

## Behavior checked

- All goals share the same row and a visible heading, including the first goal. Mobile collapse applies to the complete list.
- Item, machine, recipe and technology labels use authored German presentation text. Source catalog data and serialized IDs are unchanged. Unknown labels retain supplied custom names.
- Floor alternation follows parent output sides, with deterministic handling of conflicting parents and explicit overrides. Standard-side controls and per-floor overrides have separate meanings.
- Automatic rows respect exact input/output capacity, including fractional pipe output cases. Manual row counts remain explicit.
- Floor switches retain one world origin, machine scale, pan and zoom. The canvas percentage tracks buttons/wheel and persists on reload. Shared fit can make a small floor occupy less of the canvas; zoom is available for detail.
- Reserved shafts keep their positions across their spans and identify material, rate and connected floors. Dashed assignment leaders are references, not extra capacity-checked belt edges. Visible keys explain input, output and machines; machine descriptions include actual per-machine flow.
- The graph has a responsive tray, preserves material colors during selection, reduces adjacent-rank crossings and separates bypass stems.

## Independent review

Code and security review found and resolved two issues before delivery: stale effective-side editing when dependency orientation changed, and eager detailed routing of all hidden floors. A separate envelope probe checked 448 scenes across all side pairs and compact/full branching plans without containment failures.

The browser suite also exposed a local-session startup race: default unlocks could briefly overwrite the saved profile and create two revisions during reload. Editable readiness and persistence now wait until React's profile matches the authoritative restored room profile. The reload regression checks both the restored settings and an unchanged session revision.

The hidden-floor regression was measured with the bundled catalog, tier 8 and automatic rows: a 40 heavy modular frames/minute plan has 12 floors and 1174 machines in total. Eager detailed scenes took about 108 seconds. Cheap bounds for all floors took about 90 ms, with about 782 ms for detailed routing of the initially selected floor in the implementation probe. These are executor measurements of scene preparation, not in-game or end-to-end performance guarantees. Selecting a particularly large floor still incurs its existing detailed-routing cost.
