# Contributing

Use Node from `.node-version` and npm 11.9.0. Run `npm ci`, then `npm run check` and `npm run test:coverage`. Core modules have no network, browser, database or clock dependency. Add known-answer and negative tests for planner changes.

Open PRs as Draft. Complete Codex code and Security reviews against the current head, resolve valid findings and rerun reviews before Ready. CodeRabbit is not used in this project; do not install, authenticate or request it. Unavailable required Codex reviews block promotion; absent comments do not constitute approval. Merging and deployment require a separately agreed integration step.

UI work requires the selected screenshot and design contract from issue #5. All committed datasets and geometry must declare provenance and redistribution status. Synthetic examples are not evidence of Satisfactory balance or physical buildability.

Explicit attribution is a project requirement for external code and data. Name the source author or project, link the original source and pin the revision where available, even when a license does not require visible credit. Preserve applicable copyright notices and complete license texts in distributed copies. Record each source's own license status; attribution alone is not permission, and one dataset's license does not cover another source.

Before incorporating external code or data, establish explicit reuse permission covering the material being imported and this project's intended distribution. Do not import material with unknown license status or reuse restrictions that exclude this project. User acceptance of numeric values and source attribution do not substitute for source permission.
