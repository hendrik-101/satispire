# Security

Report suspected vulnerabilities privately using GitHub private vulnerability reporting if enabled; otherwise contact the repository owner privately. Do not publish room/invite/session capabilities in issues. No production service is deployed by this initial core slice.

Room roles and revisions are checked by the shared domain functions; adapters must supply a verified participant identity. Unverified geometry and unsupported production topology must fail explicitly. Public fixtures are original synthetic examples. Never commit game assets, raw game JSON, credentials or environment files.
